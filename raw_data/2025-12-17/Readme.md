## T_meas:
- Imgs to measure temperature of atoms when odt is off
- Tof = [5., 10., 15., 20., 25., 30.] ms
- For each tof we get 3 images to average and get an error on the sigma values
- (shim_x, shim_z) Map: 3 images for each (Ix, Iz) value, with odt ON
  - Ix = [-1100, -500, 50]
  - Iz = [-500, 0, 50]
- 3 images with odt OFF
